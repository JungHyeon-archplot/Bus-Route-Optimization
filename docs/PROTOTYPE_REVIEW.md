# 기존 시제품 검토

대상은 제공된 Python 생성기와 별도 HTML입니다. 두 파일의 로직이 다릅니다.

| 항목 | 확인 결과 | 수정 |
|---|---|---|
| HTML 정차 | (id+이름길이)%4=(id-1)%4 → 이름길이%4=3만 대상 | 명시적 ID 목록 |
| 지역 누락 | 충무로·퇴계로5가·동국대후문·동대입구 0대, 47곳 중22곳 제외 | 서비스 보존 |
| Python 정차 | 이름길이%4로 그룹 결정 | 이름 변경 불변 |
| 속도 | HTML 적용시 1~4칸, 미적용1칸 | 거리/속도 통일 |
| 수학 | 충돌 그래프 없이 i%4 | 조건과 알고리즘 분리 |
| 경로 | 최대 인접 좌표15.6km, 순환 연결21.3km; Python 49접합 중10불연속 | 연결 검증 |
| 배속 | 정차 타이머만 반영 | 엔진·재생 분리 |
| 통계 | 기다리는 버스 대기 합, 진입 후 삭제 | 누적 사건·평균·건수 |
| 승객 | 수요·목적지·정원 없음 | 이론값과 측정값 구분 |
| 표시 | HTML 정차 문자열 중복 append | 단일 표시 |

좌표·조건식 계산에 근거한 코드 검토이며 실제 교통 통계가 아닙니다.
지도·전후 조작·병목 표시 아이디어는 활용하되 원본은 legacy에 보존합니다.
