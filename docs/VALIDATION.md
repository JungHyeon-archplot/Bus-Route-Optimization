# MVP 검증 기록

2026-09-28, 가상 시나리오. Node.js 기본 테스트 러너로 로컬 검사합니다.
API 성공은 모의 XML로 검증했으며 실제 키 호출은 수행하지 않았습니다.

## 결정적 60분 실험

준비구간 36분, 관측 60분, 정차 25초, 차량 3대, 구간마다 900m, 속도10m/s.
같은 6개 정류장과 720초 차량별 계획 주기입니다.

| 지표 | 동시 출발 | 분산 출발 |
|---|---:|---:|
| 정류장 방문 기록 | 90 | 90 |
| 평균 버스 진입 지연 | 3.0556초 | 0초 |
| 누적 버스 진입 지연 | 275초 | 0초 |
| 최대 진입 대기 대수 | 2대 | 0대 |
| 이론 평균 승객 대기 | 312.6042초 | 120초 |

각 정류장의 관측 방문은 15건씩입니다. 동시 출발안도 정류장 대기와 차량 복귀 제약 때문에
완전히 같은 시각에 세 대가 서비스를 제공하지는 않습니다. 따라서 단순 360초 이론 예시와
시뮬레이터의 312.6초는 다릅니다. 정차 시작 시계열을 적분한 결과입니다.

이 표는 관측창을 명시한 결정적 예제이며 정상상태 수렴 또는 통계적 개선 검증을 주장하지 않습니다.
정원·목적지·환승·신호 지연·추월은 포함하지 않습니다.

## 검사 내용

- 22분 우체부 결과와 폐회로, 간선 커버리지
- 음수·단절 입력 거부, 홀수 정점 4개 예제, K5 5색
- 정류장 이름 변경 불변, 같은 차량 3대와 서비스 보존
- FIFO 정차와 실제 복귀 전 재출발 금지
- 승객 이론 대기의 오른쪽 경계 처리, 미관측 서비스는 null
- 배속과 엔진 분리, 누적 CSV
- 키 없는 실패·기관 오류·네트워크 실패·인코딩
- 정적 서버가 .env, .git, legacy를 제공하지 않는지 확인

브라우저에서 초기 렌더링, 시간 이동, 키보드 재생·일시정지·초기화를 확인합니다.
